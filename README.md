# SLR-Auras

**SLR-Auras** is a Minecraft project created by **Goldosmaster**.

The project adds aura-related features to Minecraft and is designed to complement the gameplay experience of the Solo Leveling: Reawakening mod ecosystem.

## Features

- Aura-related gameplay features
- Designed for Minecraft modded gameplay
- Lightweight and focused on its main purpose
- Open-source and available for community use
